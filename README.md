# Labmem04 Personal Homepage

A refined bilingual personal homepage for Labmem04, built with Vite, React, and TypeScript.

Live site: https://codex-personal-homepage-20260531184420.netlify.app

## Run Locally

```bash
npm install
npm run dev
```

## Customize

Edit `src/profile.ts` to update the name, introduction, email, and social links.
